# Gym Rank X Business: plugins

Plugins oficiais do [Gym Rank X Business](https://business.gymrankx.com).

## grx-inteligencia

Importe planilhas, conecte APIs e analise os dados de RH na Inteligência do Gym Rank X Business pelo Claude, pelo ChatGPT ou por outro assistente compatível com MCP.

**Claude Code**

```
claude plugin install grx-inteligencia --marketplace grxlabs/grx-plugins
```

Depois abra o Claude Code, digite `/mcp` e entre com a sua conta do Gym Rank X Business.

**Claude e Cowork**: em Personalizar › Plugins › Adicionar marketplace, cole `grxlabs/grx-plugins` e instale o Gym Rank X Inteligência. Em Conectores, conecte o Gym Rank X e entre com a sua conta.

**ChatGPT e outros clientes MCP**: endereço do MCP `https://srv01.gymrankx.com/api/business/mcp` (login OAuth na sua conta).

Política de privacidade: https://gymrankx.com/terms/privacy
