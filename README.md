# Gym Rank X Business: plugins

Official plugins of [Gym Rank X Business](https://business.gymrankx.com).

## grx-intelligence

Import spreadsheets, connect APIs and analyze HR data in Gym Rank X Business Intelligence from Claude, ChatGPT or any other MCP-compatible assistant.

**Claude Code**

```
claude plugin install grx-intelligence --marketplace grxlabs/grx-plugins
```

Then open Claude Code, type `/mcp` and sign in with your Gym Rank X Business account.

**Claude and Cowork**: in Customize › Plugins › Add marketplace, paste `grxlabs/grx-plugins` and install Gym Rank X Intelligence. In Connectors, connect Gym Rank X and sign in with your account.

**ChatGPT and other MCP clients**: MCP address `https://srv01.gymrankx.com/api/business/mcp` (OAuth sign-in with your account).

Documentation for agents (Markdown): https://business.gymrankx.com/docs/intelligence/llms.txt
